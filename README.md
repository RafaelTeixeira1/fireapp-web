# FireApp - Sistema de Monitoramento de Queimadas

O FireApp é um sistema inovador destinado a auxiliar a sociedade e órgãos competentes no monitoramento e combate a queimadas e incêndios florestais. O objetivo é proporcionar uma plataforma interativa para a rápida detecção, notificação e combate a incêndios, aumentando a eficiência na resposta a situações de emergência.

Este aplicativo permite o cadastro de incêndios, envio de alertas, visualização de incêndios em um mapa interativo e gestão de informações essenciais para bombeiros e autoridades.

## Funcionalidades Principais

* Cadastro de Incêndios: Os usuários podem cadastrar focos de incêndio, incluindo informações sobre sua intensidade (leve, moderado, grave) e localização no mapa interativo.
* Alertas e Notificações: O sistema envia notificações de incêndios para os usuários, especialmente moradores de áreas rurais, e também para bombeiros e órgãos competentes.
* Dashboard para Bombeiros e Autoridades: Painel de controle para bombeiros visualizarem e gerenciarem os focos de incêndio em tempo real.
* Mapeamento Interativo: Através de um mapa, os usuários podem ver os incêndios registrados e sua localização precisa.
* Cadastro de Usuários: Possibilidade de cadastro de diferentes tipos de usuários, como usuários comuns (que podem cadastrar e visualizar incêndios) e bombeiros/autoridades (que possuem acesso ao dashboard e informações detalhadas).

## Tecnologias Utilizadas

### Frontend:
* HTML, CSS, JavaScript
* Biblioteca Leaflet para visualização de mapas interativos
* Backend: (não detalhado neste momento, pode ser integrado com qualquer solução de backend como Node.js, Python Flask, Java Spring Boot ou PHP)
